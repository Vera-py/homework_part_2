# Виджет для личного кабинета клиента банка

Включает несколько функций.

## get_mask_card_number
Содержится в модуле masks.
Принимает на вход номер карты и возвращает ее маску в формате XXXX XX** **** XXXX, где X – это цифра номера.
#### Пример работы функции
7000 79** **** 6361

## get_mask_account
Содержится в модуле masks.
Принимает на вход номер счета и возвращает его маску в формате **XXXX, где X – это цифра номера.
#### Пример работы функции
**4305

## mask_account_card
Содержится в модуле widget.
Принимать строку, содержащую тип и номер карты или номер счета. Возвращать строку с замаскированным номером.
Для карт и счетов разные типы маскировки:
– Название Карты + XXXX XX** **** XXXX для банковской карты
– Счет + **XXXX для счёта.
#### Пример работы функции
Для банковской карты
Visa Platinum 7000 79** **** 6361
Для счета
Счет **4305

## get_date
Содержится в модуле widget.
Принимает на вход строку с датой в формате "2024-03-11T02:26:18.671407" и возвращает строку с датой в формате "ДД.ММ.ГГГГ".

## filter_by_state
Содержится в модуле processing.
Принимает список словарей и опционально значение для ключа state (по умолчанию "EXECUTED") и возвращает новый список, содержащий только те словари, у которых ключ state соответствует указанному значению.
#### Пример работы функции
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

## sort_by_date
Содержится в модуле processing.
Принимает список словарей и возвращает его отсортированным по убыванию даты банковской операции.
#### Пример работы функции
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
